## What it is

`octofhir-sof` is a Rust toolkit for
[SQL on FHIR 3.0](https://build.fhir.org/ig/HL7/sql-on-fhir/)
(`hl7.fhir.uv.sql-on-fhir`, the HL7 continuous build of the 3.0.0 ballot): it
parses `ViewDefinition` resources and turns FHIR data into flat tables, and it
carries the SQL layer 3.0 adds on top — SQLQuery / SQLView libraries over
views, value sets and concept maps. Views written for 2.0 / 2.1 run unchanged.
The library is network-free and embeddable; the CLI is a thin shell over it.

- **Database-free in-memory evaluator** over `serde_json`, and a **PostgreSQL /
  DuckDB SQL generator** — both pass the full official content-test suite
  (144/144).
- **Version-agnostic execution**: the engine navigates resource JSON directly,
  so the same view runs unchanged over R4, R4B, R5 or R6.
- **Writers**: CSV, NDJSON, JSON, and Parquet (feature-gated).
- **The 3.0 view model**: `repeat` and `%rowIndex` on both paths, and the
  structural rules checked before a view runs.
- **The 3.0 SQL layer**: see [SQL on FHIR 3.0 jobs](/sof/guides/sql-on-fhir-3/).
- Every example of the 3.0 guide is part of the test suite.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/octofhir/sof/main/install.sh | sh
```

See [Install](/sof/install/) for `cargo install`, prebuilt binaries, and
building from source.
